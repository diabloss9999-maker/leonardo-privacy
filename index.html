Leonardo 개인정보처리방침

시행일: 2026년 4월 7일

Leonardo는 개인 투자자를 위한 주식 포트폴리오 관리 앱으로, 사용자의 개인정보를 소중히 보호합니다.

1. 수집하는 개인정보

필수 수집 항목:

  • 매매 기록 데이터 (종목, 수량, 가격, 날짜)
  • 관심종목 목록
  • 앱 설정 (테마, 통화, 갱신 주기)

선택 수집 항목:

  • AI 분석 사용 시: Claude API 키 (암호화 저장)

수집하지 않는 항목: 위치정보, 기기식별자, 광고ID, 연락처, 사진 등을 수집하지 않습니다.

2. 개인정보의 이용 목적

  • 포트폴리오 관리 및 손익 계산
  • 기술적 분석 지표 제공 (RSI, MACD, 볼린저밴드 등)
  • AI 기반 투자 인사이트 생성 (선택적)
  • 실시간 시세 조회 및 알림

3. 개인정보의 보관 및 저장

기본 원칙: 모든 데이터는 사용자의 기기(로컬 SQLite)에만 저장됩니다. 서버로 전송되지 않습니다.
  • 로컬 저장: 매매기록, 관심종목, 설정 등 모든 데이터는 기기 내부에만 저장
  • 시세 조회: Yahoo Finance, FMP API를 통해 공개 시세 데이터만 조회 (개인정보 미전송)
  • AI 분석: 사용자가 직접 설정한 경우에만 Claude API로 포트폴리오 요약 데이터 전송, 분석 완료 후 서버에 저장되지 않음
  • PIN 보안: SHA-256 해시로 변환되어 저장, 원본 PIN은 어디에도 저장되지 않음

4. 개인정보의 제3자 제공

Leonardo는 사용자의 개인정보를 제3자에게 제공하지 않습니다. 단, 법률에 의해 요구되는 경우 예외로 합니다.

5. 이용하는 외부 서비스

  • Yahoo Finance / FMP: 공개 시세 데이터 조회 (개인정보 미전송)
  • Fear & Greed Index: 시장 심리 지수 조회
  • Anthropic Claude API: AI 분석 (사용자 선택 시에만, 포트폴리오 요약만 전송)

6. 사용자의 권리

  • 앱 삭제 시 모든 로컬 데이터가 즉시 삭제됩니다
  • 설정에서 JSON 내보내기로 데이터를 백업할 수 있습니다
  • 모든 저장된 데이터를 앱 내에서 확인/삭제할 수 있습니다

7. 투자 면책조항

Leonardo는 투자 조언을 제공하지 않습니다. 앱에서 제공하는 모든 분석, 시그널, 예측은 참고용이며, 실제 투자 결정은 사용자 본인의 판단과 책임 하에 이루어져야 합니다. 투자에 따른 손실에 대해 Leonardo는 어떠한 책임도 지지 않습니다.

8. 아동의 개인정보 보호

Leonardo는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

9. 개인정보처리방침의 변경

본 방침이 변경되는 경우, 앱 내 공지를 통해 안내합니다.
